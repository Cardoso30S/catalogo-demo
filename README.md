# Catálogo digital · demonstração

Demonstração pública do catálogo digital para distribuidoras e chaveiros:
catálogo online, PDF pronto para enviar e pedidos pelo WhatsApp.

**Todos os produtos, marcas, códigos e preços são fictícios.** Nomes de montadoras
aparecem só para indicar a aplicação.

- Visão do cliente: navegue pelas abas, use a busca, monte um pedido e envie pelo WhatsApp, ou baixe o PDF.
- Painel de edição: toque em **Entrar** no rodapé (na demonstração não pede senha).
  O que for editado fica salvo só no navegador de quem está testando.
  **Produtos → Restaurar exemplo** volta ao catálogo original.

Site estático (HTML, CSS e JavaScript), sem servidor. As configurações ficam em `js/config.js`
(nome, cores, WhatsApp que recebe os pedidos e catálogos).
